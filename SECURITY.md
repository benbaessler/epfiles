# Security Policy

## Reporting a Vulnerability

**Do not open public issues for security vulnerabilities.**

Instead, please report them privately by emailing the maintainers directly.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## Response Timeline

We aim to acknowledge reports within 48 hours and provide a resolution timeline within 7 days.

## Supported Versions

Security updates are provided for the latest release only.

Create one or multiple git commits with messages relevant to what was done in those respective code changes. Do not push the changes, only commit. Avoid commit descriptions or keep brief if you have to.

You do not have to add every single file to a commit. If there are files which you think should be untracked and added to .gitignore based on optimization or best practices, then make this change in .gitignore and commit it.

IMPORTANT: strictly follow the commit message guidelines from the Cursor User rules
